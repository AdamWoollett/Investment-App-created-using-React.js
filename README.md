An investment app application where a user can calculate the returns on an investment over a user-specified number of years by inputting relevant values. 
The app dynamically displays a table of results as the user adjusts values in the input fields.
The app contains error handling to prevent users specifying 0 years and specifying negative values.
There is also functionality to export the displayed results in a pdf. 
The app makes use of a setTimeout function to simulate the loading of the pdf download, with a dialogue box that appears when this timer is running to let the user know that work is being done.
This app was created using the Vite framework.
